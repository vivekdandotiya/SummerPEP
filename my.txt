========================================================================
                  L2/DEVOPS 70-DAY PLACEMENT STUDY PLAN                 
========================================================================

DAY 1: OS Fundamentals (Ubuntu/RHEL)
Subject: LINUX
Learning Objectives: Understand Linux distributions, kernel vs user space, filesystem hierarchy (/bin, /etc, /usr, /var).
Hands-on Tasks: Install a Linux VM; explore / directory structure.
Interview Prep: Explain /etc vs /home.
--------------------------------------------------------------------------------

DAY 2: Essential Linux Commands
Subject: LINUX
Learning Objectives: Learn pwd, ls, cd, mkdir, rm, cp, mv, touch, cat, head, tail, grep, find, locate.
Hands-on Tasks: Practice file operations: create/move/copy files, use grep search.
Interview Prep: How to find large files?
--------------------------------------------------------------------------------

DAY 3: Users & Permissions
Subject: LINUX
Learning Objectives: Manage users/groups; file permission bits (rwx), chmod, chown, sudo.
Hands-on Tasks: Create users/groups; change file ownership/permissions.
Interview Prep: Explain chmod 755.
--------------------------------------------------------------------------------

DAY 4: Processes & SSH
Subject: LINUX
Learning Objectives: Understand processes (ps, top, kill), services (systemctl, journalctl); SSH basics (connectivity, key auth).
Hands-on Tasks: Start/stop a service, view logs; set up SSH key login.
Interview Prep: Difference between kill and kill -9.
--------------------------------------------------------------------------------

DAY 5: Package Mgmt & OSI Model
Subject: NETWORKING
Learning Objectives: Learn Debian (apt) vs RHEL (yum/dnf) package tools. Review networking models: OSI vs TCP/IP layers, TCP vs UDP.
Hands-on Tasks: Install/remove packages (e.g. sudo apt install nginx); map out OSI layers for TCP/UDP, HTTP.
Interview Prep: When to use TCP vs UDP?
--------------------------------------------------------------------------------

DAY 6: Docker Basics
Subject: DOCKER
Learning Objectives: Intro to Docker: container vs VM, Docker client-server. Key commands: docker pull/run/ps/images.
Hands-on Tasks: Install Docker; pull an image (e.g. nginx), run/inspect/stop a container.
Interview Prep: Explain image vs container.
--------------------------------------------------------------------------------

DAY 7: Docker Advanced
Subject: DOCKER
Learning Objectives: Intermediate Docker: docker stop/rm, exec, logs; Dockerfile syntax (FROM, RUN, CMD); port mapping, volumes, networking. Troubleshooting (container not starting).
Hands-on Tasks: Write a simple Dockerfile (e.g. Python app), build & run; experiment with exposing ports.
Interview Prep: How to persist data with Docker?
--------------------------------------------------------------------------------

DAY 8: Monitoring & Bash Intro
Subject: LINUX
Learning Objectives: Monitoring concepts (metrics, alerts). Nagios and Grafana basics. Bash scripting intro: shebang, variables, I/O.
Hands-on Tasks: Spin up a Grafana or Nagios container; write a bash script with variables, echo.
Interview Prep: What is Prometheus exporter?
--------------------------------------------------------------------------------

DAY 9: Prometheus & Bash Scripting
Subject: LINUX
Learning Objectives: Prometheus fundamentals (metrics collection, exporters); Zabbix intro. Bash scripting (loops, conditionals, functions).
Hands-on Tasks: Run a simple Prometheus exporter (e.g. Node exporter); write a bash loop with if.
Interview Prep: Write a bash for loop example.
--------------------------------------------------------------------------------

DAY 10: Bash & Python & Networking
Subject: LINUX
Learning Objectives: Finish Bash (file handling scripts, cron jobs). Python basics: variables, data types, loops, functions, lists, dicts, file I/O. Networking intro (DNS, HTTP, firewalls).
Hands-on Tasks: Automate a simple backup in bash. Write a Python script to parse a file.
Interview Prep: Python list vs dict.
--------------------------------------------------------------------------------

DAY 11: Storage: Disks & LVM
Subject: LINUX
Learning Objectives: Disk partitioning (fdisk, lsblk). LVM concepts (PV, VG, LV) for flexible storage.
Hands-on Tasks: Use fdisk to partition a disk; create LVM PV/VG/LV; format and mount.
Interview Prep: Explain the steps to extend a filesystem with LVM.
--------------------------------------------------------------------------------

DAY 12: Storage: Filesharing & Backup
Subject: LINUX
Learning Objectives: NFS setup, SFTP usage, backup strategies (e.g. rsync).
Hands-on Tasks: Configure an NFS share between two VMs; transfer a file via SFTP; schedule a cron backup.
Interview Prep: Describe a full vs incremental backup.
--------------------------------------------------------------------------------

DAY 13: Virtualization Concepts
Subject: DOCKER
Learning Objectives: Hypervisor types (Type-1 vs Type-2), VMware/VirtualBox overview, snapshots/cloning.
Hands-on Tasks: Install VirtualBox or VMware Player, create a VM, take snapshots.
Interview Prep: Differences between VM and container.
--------------------------------------------------------------------------------

DAY 14: AWS Cloud Basics (EC2/S3/IAM)
Subject: CLOUD
Learning Objectives: AWS IaaS: EC2 instances (launch/configure), S3 object storage, IAM roles.
Hands-on Tasks: Launch a free-tier EC2 VM, create an S3 bucket and upload a file, create an IAM user.
Interview Prep: What is an EC2 instance?
--------------------------------------------------------------------------------

DAY 15: Azure Cloud Basics (VM/Storage)
Subject: CLOUD
Learning Objectives: Azure fundamentals: Resource Groups, Virtual Machines, Storage Accounts, Virtual Network, NSG (firewall).
Hands-on Tasks: Provision an Azure VM (Linux/Windows) in a VNet; attach storage.
Interview Prep: Azure VM vs AWS EC2.
--------------------------------------------------------------------------------

DAY 16: Git Version Control
Subject: GIT
Learning Objectives: Git basics: repositories, clone, add, commit, push, pull, branching/merging.
Hands-on Tasks: Initialize a Git repo, create/merge a branch, resolve a merge conflict.
Interview Prep: Git vs SVN differences.
--------------------------------------------------------------------------------

DAY 17: Jira & ServiceNow Intro
Subject: SUPPORT
Learning Objectives: Issue tracking: Jira (projects, tickets, sprints, workflows) and ServiceNow (Incident, Change, Problem, SLA concepts).
Hands-on Tasks: Create/sample Jira tickets and workflow; explore a ServiceNow instance (incidents, SLAs).
Interview Prep: Define incident vs problem.
--------------------------------------------------------------------------------

DAY 18: Confluence & Documentation
Subject: SUPPORT
Learning Objectives: Confluence basics (spaces, pages); writing SOP/knowledge-base articles for IT processes.
Hands-on Tasks: Create a Confluence page (e.g. runbook template) documenting a common task.
Interview Prep: Why is documentation important?
--------------------------------------------------------------------------------

DAY 19: L2 Support Fundamentals
Subject: SUPPORT
Learning Objectives: L1->L2->L3 ticket flow; Incident vs Problem vs Change; escalation criteria; SLAs (response/resolution times).
Hands-on Tasks: Case-study: Triaging sample tickets, deciding escalation, tracking SLAs.
Interview Prep: How do you define Root Cause (RCA)?
--------------------------------------------------------------------------------

DAY 20: L2 Support Communication
Subject: SUPPORT
Learning Objectives: Professional communication and reports: status updates, RCA report structure; service request handling.
Hands-on Tasks: Draft a mock incident update email and an RCA summary for an example outage.
Interview Prep: What to include in an RCA report?
--------------------------------------------------------------------------------

DAY 21: Linux & Networking Review
Subject: NETWORKING
Learning Objectives: Review key Linux skills (users, processes, commands) and networking (OSI layers, TCP/UDP, DNS, DHCP, firewalls).
Hands-on Tasks: Quick quiz: set permissions; troubleshoot a mock network issue.
Interview Prep: Explain subnetting basics.
--------------------------------------------------------------------------------

DAY 22: Database Basics (SQL)
Subject: NETWORKING
Learning Objectives: Relational model, ER diagrams, primary/foreign keys, ACID. SQL queries (SELECT, JOIN, GROUP BY).
Hands-on Tasks: Sketch a simple schema; run sample SQL queries on a database.
Interview Prep: What is a JOIN?
--------------------------------------------------------------------------------

DAY 23: Networking Deep Dive
Subject: NETWORKING
Learning Objectives: Advanced CN: DNS hierarchy, DHCP, NAT/PAT, SNMP (monitoring), LDAP (auth), VPN types.
Hands-on Tasks: Set up a simple DNS lookup; configure SNMP agent; test a VPN tunnel.
Interview Prep: How does DHCP work?
--------------------------------------------------------------------------------

DAY 24: Storage & Backup Review
Subject: LINUX
Learning Objectives: Review LVM, filesystems. Backup/restore (tar/rsync, snapshot strategies).
Hands-on Tasks: Use tar or rsync to backup files; simulate data restore.
Interview Prep: Pros/cons of tape vs disk backup.
--------------------------------------------------------------------------------

DAY 25: Virtualization Review
Subject: DOCKER
Learning Objectives: Recap hypervisors (ESXi/Hyper-V basics), containers vs VMs, VirtualBox network modes.
Hands-on Tasks: Experiment with VirtualBox networking (NAT/bridged); review VM/host resources.
Interview Prep: What is VMware ESXi?
--------------------------------------------------------------------------------

DAY 26: Cloud Services Review
Subject: CLOUD
Learning Objectives: Recap AWS/Azure: EC2 (types, scaling), S3/EBS, Azure VMs, Storage, VNets.
Hands-on Tasks: Use AWS CLI/Azure CLI for sample commands (e.g. list instances).
Interview Prep: What are AWS Availability Zones?
--------------------------------------------------------------------------------

DAY 27: Git & CI/CD Basics
Subject: GIT
Learning Objectives: Git advanced (rebasing, tags). Introduction to CI/CD (Jenkins or GitHub Actions basics).
Hands-on Tasks: Configure a simple GitHub Actions workflow to auto-run tests on push.
Interview Prep: Benefits of CI/CD pipelines.
--------------------------------------------------------------------------------

DAY 28: Jira/ServiceNow Review
Subject: SUPPORT
Learning Objectives: Recap Jira fields (Epic, Story, Task), ServiceNow modules (Incident, Change, Problem).
Hands-on Tasks: Draft a Jira user story; simulate a change request in ServiceNow with rollback plan.
Interview Prep: What is an SLA in ITIL?
--------------------------------------------------------------------------------

DAY 29: Confluence & Docs Review
Subject: SUPPORT
Learning Objectives: Recap Confluence usage and documentation best-practices (SOPs, KBs).
Hands-on Tasks: Organize a Confluence space (pages and hierarchy) for a sample project.
Interview Prep: What goes into a good SOP?
--------------------------------------------------------------------------------
